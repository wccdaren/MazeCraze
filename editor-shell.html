    Resizing keeps bottom-left coordinates. Shrinking can crop cells. Changing the default replaces cells currently using the old default. A new map number updates this map’s NIDs and their references; explicit transport map numbers stay unchanged.

    THE MAPMAKER’S FIELD GUIDE

    Start with a winding path.

    Choose New map, open a local .txt file, or open an example. Map settings controls the size, starting location, default and border blocks, view windows, variables, and export layout.

    Select a palette block and paint by clicking or dragging. Drag a palette tile onto the canvas to place it. Rectangle draws a filled rectangle; Fill replaces a connected area; Erase uses the map default. Start sets the player’s starting cell. Pick selects a placed block. Pan drags the map without painting.

    Double-click a palette block, or choose Edit selected block, to edit its pictures, inventory properties, choices, tests, and pass/fail outcomes. Each block type can have its own image; an interactive tree may look identical to a wall tree.

    Use Ctrl/Cmd Z to undo and Ctrl/Cmd Shift Z to redo. With the map focused, arrow keys move the cursor and Space applies a tool. B/E/R/F/S/I/H select tools. Go to cell also provides an exact coordinate control.

    Export downloads a game-compatible .txt file. Your original file is never overwritten or uploaded. Pictures remain separate files. Imported comments move together to the top; unknown settings are retained. Skipped map rows are reported, and the original imported text can be downloaded before making corrections.

    Open a map lists current website files from main-config.txt when this editor is hosted with the game. Refresh map list finds newly added maps. Bundled examples are separate offline copies. Export and SFTP your edits to publish; opening a website map never writes to the server.

    This editor runs offline by double-clicking editor.html. The game itself still needs HTTP(S). Player-variable definitions and the map file directory live in main-config.txt, outside this map editor.

    On your game website, Test from Start runs a fresh copy of this map. Back to Edit pauses the test. Resume Test keeps that run, including its old map design. After editing, choose Test from Start to try your changes. Local image previews must be uploaded separately to appear in the game.
